## Hakam Data Studio implementation

For the existing Hakam Data Studio site, the single source of truth is hakam-web/src/data/weeklyUpdates.js. Preserve its current draft to published approval workflow. Every new entry should include a dated availability label, a concrete before/after example, analyst implications, a qualitative job-market signal, and primary references. Run npm run editorial:check before committing. Published entries must have a real date and at least one primary source; drafts may remain unlisted while they are reviewed.
