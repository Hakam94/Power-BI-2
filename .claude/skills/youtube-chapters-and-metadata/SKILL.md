# YouTube Chapters & Metadata Skill (@HakamDataStudio)

Automated YouTube metadata and chapter generation pipeline for Hakam Data Studio.

---

## 1. Features

- **Timestamped Chapters**: Auto-calculates key topic changes from transcripts (`00:00 Intro`, `00:33 Context`, `02:00 Capabilities`, `05:30 MCP Protocol`, `07:00 Fabric IQ`).
- **SEO Title Generator**: Generates high-CTR titles incorporating key terms (Power BI, AI Agents, MCP, Fabric IQ).
- **Description & Hashtags**: Generates structured descriptions with timestamps, key takeaways, link callouts, and hashtags (`#PowerBI #AIAgents #FabricIQ`).
