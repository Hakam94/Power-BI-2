## 🎯 What You'll Learn

In Part 1, you'll:
* **Install Power BI Desktop** and set up your environment
* **Import raw data** from Excel into Power BI
* **Clean and prepare data** using Power Query (basic transformations)
* **Build your first visuals** (charts, tables, KPIs)
* **Create your initial dashboard layout** with slicers and filters
* **Understand the basics** of Power BI interface and navigation

---

## 🛠️ Step-by-Step Breakdown

### 1. 🔧 Installation & Setup
* Download and install Power BI Desktop from the [official Microsoft website](https://powerbi.microsoft.com/en-us/desktop/)
* Launch Power BI and familiarize yourself with the interface
* Explore the Ribbon menu (Home, Insert, Modeling, View, Help)

### 2. 📥 Import Data from Excel
* Go to **Home** → **Get Data** → **Excel**
* Select the `CoffeeShop_Sales.xlsx` dataset (or similar)
* Load the sales data into Power BI

### 3. 🧹 Basic Data Cleaning (Power Query)
* Review the loaded data for missing values or inconsistencies
* Rename columns for clarity (e.g., ensure headers are proper)
* Filter out any invalid records
* Click **Close & Apply** to load the cleaned data into the model

### 4. 📊 Build Your First Visuals
* Create a **Card** to display Total Revenue
* Create a **Column Chart** to show Sales by Store or Product
* Create a **Table** to display detailed sales records
* Add **Slicers** for Date, Store, or Product filters

### 5. 🎨 Design Your Initial Layout
* Organize visuals on the report canvas (drag and resize)
* Add titles and labels for clarity
* Align visuals for a clean, professional appearance
* Save your report as `Café-part 1.pbix`

## 🧠 Key Concepts

| Concept | Description |
|---------|-------------|
| **Power BI Desktop** | The free desktop application for building Power BI reports and dashboards |
| **Power Query** | Data transformation tool to clean and prepare data |
| **Visualizations** | Charts, tables, cards, slicers, and other visual elements |
| **Slicer** | Interactive filter that allows users to filter data dynamically |
| **Report Canvas** | The blank page where you design your dashboard layout |

---

## 💡 Tips & Best Practices

* **Start Small**: Don't overcomplicate your first dashboard. Focus on a few key metrics.
* **Name Your Fields**: Use clear, descriptive names for columns to make formulas easier to write later.
* **Group Related Visuals**: Place visuals that show related information close together.
* **Test Your Slicers**: Verify that filters work correctly before publishing.
